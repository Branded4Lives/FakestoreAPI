# FakeStore E-Commerce App

## Overview
This is a React-based e-commerce application that uses FakeStoreAPI to fetch and manage product data. The app allows users to view products, see details, and perform create, update, and delete operations.

## Features
- View all products from API
- View individual product details
- Add new products (POST)
- Edit existing products (PUT)
- Delete products with confirmation (DELETE)
- Shopping cart functionality
- Responsive design using React Bootstrap

## Tech Used
- React
- React Router
- React Bootstrap
- FakeStoreAPI
- JavaScript (Fetch API)

## Important Note
FakeStoreAPI is a mock API. POST, PUT, and DELETE requests will return success responses, but changes will not persist.

## How to Run
1. Clone the repo
2. Run `npm install`
3. Run `npm run dev`
4. Open the local URL
